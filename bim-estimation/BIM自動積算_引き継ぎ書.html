BIM自動積算 引き継ぎ書

Archicad のモデルから数量（長さ・面積・体積など）を自動集計し、CSVを出力するスクリプト「BIM自動積算.py」のセットアップ・運用手順書です。

対象: Archicad 25〜29 をお使いの方（プログラミング知識は不要） 所要時間: 約15分 作成日: 2026-08-16

全体像 — 仕組みを1分で理解する

Archicad は起動中、パソコン内部でJSON命令を受け付ける窓口（ポート 19723）を自動的に開いています。無料アドオン「Tapir」を入れるとこの窓口で使える命令が大幅に増え、「BIM自動積算.py」はその窓口に命令を送って数量を取り出し、CSVにまとめます。

ステップ 1Python をインストールする

  1. 公式サイト https://www.python.org/downloads/ を開き、「Download Python 3.x.x」の黄色いボタンをクリックしてインストーラーをダウンロードします。
  2. インストーラーを起動したら、最初の画面で必ず「Add python.exe to PATH」にチェックを入れてから「Install Now」をクリックします（ここが一番のつまずきポイントです）。
  3. Mac の場合はダウンロードした .pkg をそのままインストールすればOKです。

インストール確認

Windows はスタートメニューで「cmd」と入力してコマンドプロンプトを開き、次を入力して Enter：

python --version

Python 3.12.x のようにバージョンが表示されれば成功です。（Mac はターミナルで python3 --version）

表示されない場合: 「Add python.exe to PATH」のチェックを忘れた可能性が高いです。インストーラーをもう一度実行し「Uninstall」→ 再インストール（チェックを入れて）が確実です。

ステップ 2Tapir アドオンをインストールする

Tapir は Archicad に自動化用のJSONコマンドを追加する無料のオープンソースアドオンです（開発: ENZYME-APD）。お使いの Archicad のバージョンと OS に合ったファイルを1つダウンロードしてください。

Archicad への組み込み手順

  1. Mac の場合は zip をダブルクリックで解凍しておきます（.bundle ができます）。Windows は .apx のままでOK。
  2. Archicad を起動し、メニューの ［オプション］→［アドオンマネージャー...］ を開きます。
  3. ［有効なアドオンのリストを編集］（Edit List of Available Add-Ons）タブで［追加...］をクリックし、ダウンロードしたファイルを選択して「OK」。
  4. Archicad のメニューバーに 「Tapir」メニュー（または Interoperability 内の Tapir 項目）が表示されれば成功です。

注意: Archicad のバージョンとファイルのバージョン（AC29 など）が一致していないと読み込めません。またダウンロードしたファイルは、消さない場所（例: ドキュメント\Archicad\Addons など）に置いてから追加してください。

ステップ 3BIM自動積算.py をダウンロードする

下の緑のボタンを押すと、スクリプト本体がそのままダウンロードされます（このHTMLファイル内に埋め込んであるため、ネット接続がなくてもダウンロードできます）。

⬇ BIM自動積算.py をダウンロード GitHub から入手（予備）

  • 保存先はどこでも構いません。おすすめは デスクトップに「BIM積算」フォルダを作ってそこに置くことです（結果のCSVも同じ場所に出力されます）。
  • ファイル名は BIM自動積算.py のままにしてください。

ブラウザに「安全でない可能性」と表示された場合: 中身はテキストのPythonスクリプトです。「保存」「継続」を選択してください。気になる場合はメモ帳で開けば全コードを確認できます。

ステップ 4実行する

  1. Archicad を起動し、積算したいプロジェクトを開いておきます（これが最重要。閉じていると接続エラーになります）。
  2. BIM自動積算.py をダブルクリックします。黒いウィンドウが開き、処理状況が表示されます。
  3. 「完了しました」と表示されたら、スクリプトと同じフォルダに2つのCSVができています。Enter キーでウィンドウを閉じます。

コマンドプロンプトから実行する場合（オプション指定ができます）:

cd デスクトップ\BIM積算
python BIM自動積算.py               … プロジェクトの全要素を集計
python BIM自動積算.py --selected    … Archicadで選択中の要素だけ集計
python BIM自動積算.py --outdir C:\out  … 出力先フォルダを指定
python BIM自動積算.py --port 19724  … Archicadを複数起動しているとき

Mac の場合はターミナルで python3 BIM自動積算.py と入力します。

出力されるファイル

ファイル内容
BIM積算_明細_日時.csv1要素＝1行の明細。種別／ElementID／階／GUID／高さ・幅・厚み・長さ・面積・体積／金額
BIM積算_集計_日時.csv要素種別×階ごとの個数・数量合計・金額合計と、種別ごとの「★合計」行
  • 単位はメートル系（m / m² / m³）です。
  • UTF-8（BOM付き）で保存されるため、Excel でダブルクリックしてもそのまま文字化けせずに開けます。
  • 要素の種類によって取得できない数量は空欄になります（例: ドアに体積はありません）。

応用単価を設定して概算金額を出す

BIM自動積算.py をメモ帳などで開くと、冒頭に UNIT_PRICES（単価表）があります。行頭の # を外して単価を入れるだけで金額列が計算されます。

UNIT_PRICES = {
    '壁':     ('体積', 45000),   # 壁は 45,000円/m3 で計算
    'スラブ': ('体積', 38000),
    'ドア':   ('個',   80000),   # ドアは 1枚 80,000円
}
  • 基準は '体積'（円/m³）・'面積'（円/m²）・'長さ'（円/m）・'個'（円/個）の4種類です。
  • 種別名は明細CSVの「種別」列の文字列（壁・柱・梁・スラブ・屋根・ゾーン・ドア・窓 など）と一致させてください。
  • 保存するときは文字コード UTF-8 のまま保存してください（メモ帳は既定でUTF-8です）。

トラブルシューティング

症状原因と対処
「Archicad に接続できませんでした」Archicad が起動していない／プロジェクトを開いていない。起動して開いてから再実行。複数起動時は --port 19724 を試す（2つ目の Archicad はポート番号が1つずつ増えます）。
「Tapir アドオンが見つかりませんでした」ステップ2が未完了、またはバージョン違いのファイルを入れている。アドオンマネージャーで Tapir にチェックが入っているか確認。
「python は認識されていません」Python の PATH 設定漏れ。ステップ1の「Add python.exe to PATH」を参照して再インストール。
ダブルクリックでメモ帳が開いてしまう.py がエディタに関連付けられている。右クリック→「プログラムから開く」→ Python を選択。またはコマンドプロンプトから実行。
CSV が Excel で文字化けする通常は起きません（BOM付きUTF-8）。起きた場合は Excel の「データ」→「テキストまたはCSVから」で文字コード UTF-8 を指定して取り込み。
数量列の一部が空欄その要素種別に該当する数量が存在しない（正常な動作）。より詳細な数量が必要な場合は下記「発展」参照。
要素数が多く時間がかかる300件ずつ処理して進捗を表示します。数千要素で数分かかることがあります。--selected で対象を絞るのも有効。
Tapir を入れてから Archicad の調子が悪い気がする（困ったときの戻し方）無効化すればいつでも元に戻せます。［オプション］→［アドオンマネージャー...］で Tapir のチェックを外して「OK」→ Archicad を再起動（またはアドオンファイル自体を一時的に別フォルダへ移動してから起動）。Archicad 本体やプロジェクトデータには影響しません。なお、バージョン違いのファイル（例: AC28 に AC29 用）を入れた場合はクラッシュではなく単に読み込まれないだけです。

技術メモ（引き継ぎを受けて改造する方へ）

スクリプトは Python 標準ライブラリのみで書かれており、処理の流れは次のとおりです。

  1. API.GetProductInfo — Archicad への接続確認（公式JSONコマンド）
  2. TapirCommand.GetAddOnVersion — Tapir の存在確認
  3. TapirCommand.GetAllElements（または GetSelectedElements）— 対象要素のGUID一覧を取得
  4. TapirCommand.GetDetailsOfElements — 要素種別・所属階を取得
  5. TapirCommand.GetStories — 階名の解決
  6. API.GetAllPropertyNames ＋ API.GetPropertyIds — 使用可能な組み込み数量プロパティ（General_Height / General_Volume 等）を自動検出。Archicad のバージョン差で存在しないプロパティは自動でスキップします。
  7. TapirCommand.GetPropertyValuesOfElements — 数量値を300件ずつ一括取得
  8. Python 側で 種別×階 に集計し、CSV（utf-8-sig）で出力

発展させる場合のヒント:

  • 仕上・スキン別の数量が必要なら、Tapir の GetCompositesCommand や GetBuildingMaterialPhysicalProperties を組み合わせる。
  • ユーザー定義プロパティ（自社の積算コードなど）は API.GetPropertyIds に {"type":"UserDefined","localizedName":["グループ名","プロパティ名"]} を渡せば同じ仕組みで取得できます。
  • コマンド一覧・仕様: Tapir コマンドリファレンス
