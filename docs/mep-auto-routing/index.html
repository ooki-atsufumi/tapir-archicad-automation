Archicad 29 / Tapir Extension / MEP Auto-Routing

Generate MEP piping with a single click

Select the fixtures, indoor/outdoor units, or ventilation equipment, then press one button in the Tapir palette. Behind the scenes, the tool computes slope, ceiling-void level, grid-parallel routing, and structural clash checks, and builds real MEP piping elements directly in the 3D model. This document explains "what is actually happening" for people who only use Archicad, not Python.

01Overview

Select and click — three MEP systems, auto-routed

Select the relevant equipment, then press the corresponding button in the Tapir palette. Behind the scenes, a route is calculated according to design standards and generated as real MEP piping elements in the model. Newly generated piping is highlighted in red for review, and nothing about the building itself is ever touched.

Drainage auto-routing

Drops from each fixture below the floor, rises through a vertical riser inside the pipe shaft (PS), and continues underground to the discharge point. Slope is determined automatically from pipe diameter.

Select → fixtures (multiple) + a discharge-point marker
Refrigerant auto-routing

Runs horizontally through the ceiling void from indoor units (e.g. ceiling-cassette type) and rises directly under the outdoor unit. Generates a parallel pair of liquid and gas lines.

Select → indoor units (multiple) + an outdoor unit
Duct auto-routing

Runs a duct at a right angle from ventilation equipment to the nearest exterior wall, and automatically places an exterior hood there. Duct size is determined from airflow using the equal-friction method.

Select → ventilation equipment (+ exterior hood)

04Palette Reference

What each button does

The palette has six buttons. A typical drainage workflow is "Generate PS morph → (adjust its position) → Drainage auto-routing", followed by "Create override rule" / "Clear highlight" for review.

Generate PS morphDrainage — preparation step Places a translucent morph at each pipe-shaft (PS) location, to serve as the riser's reference geometry.
What to select
  • Select a PS zone and run → generates at that exact location (most reliable)
  • No selection → auto-detects zones whose name contains PS / DS / MB (electrical "EPS" zones are excluded)
  • If the model has no zones, you may place a morph at least 2 m tall by hand instead
What happens internally
  1. Reads the zone's 3D bounding box
  2. Groups by plan position (rounded to 0.5 m) and merges same-position PS shafts across stories into one continuous vertical morph
  3. Extends down to the underground horizontal-run level, and slightly above the top
  4. Skips positions that already overlap an existing morph on re-run
What to do next

Adjust the position and size of the generated morph to match the real PS → select the fixtures + the discharge-point marker → run "Drainage auto-routing". The riser will follow the adjusted morph's position.

Drainage auto-routingDrainage Fixture → drop below floor → grouped horizontal run → PS riser → underground → discharge point. Slope is set automatically from pipe diameter.
What to select
  • Fixtures (any number) — anything other than a morph is treated as a fixture
  • Discharge marker (one morph) — the drainage outlet point; its bottom-face center defines both the point and its depth
What gets generated
  • A drainage route as real MEP piping elements: Ø100 main / Ø75 branch
What happens internally
  1. Auto-classifies the selection: morph = discharge point, everything else = fixture
  2. Drops each fixture below the floor by drop (default 0.5 m)
  3. Groups fixtures on the same story within 4 m into a single horizontal run
  4. Chooses the riser position, preferring a PS-range morph, then a PS zone, then a direct connection
  5. Sets a downward slope automatically from pipe diameter per SHASE-S 206
  6. Checks whether beam / slab penetrations are structurally valid
Key settings (CONFIG)

diameter 0.1 (Ø100 main) / branch_diameter 0.075 (Ø75 branch) / slope auto (linked to diameter) or a fixed value e.g. 100 for 1/100 / drop 0.5 / group_distance 4.0 m / ps_mode morph (prefer the range morph) / check_structure True

Refrigerant auto-routingRefrigerant / HVAC Indoor unit → routed through the ceiling void → rises directly under the outdoor unit. Generates a parallel pair of liquid and gas lines.
What to select
  • Indoor units (objects, any number, across multiple stories)
  • Outdoor units (morphs, any number)
What gets generated
  • A parallel pair: liquid line (Ø9.52) + gas line (Ø15.88)
What happens internally
  1. Classifies objects as indoor units and morphs as outdoor units
  2. Assigns each indoor unit to its nearest outdoor unit
  3. Groups nearby indoor units on the same story (default within 8 m) into one main line
  4. Runs through the ceiling void (indoor-unit top + 0.3 m), grid-parallel
  5. Drops into a vertical shaft directly under the outdoor unit and connects
  6. Estimates equivalent length and warns if it exceeds the chargeless or maximum piping length
Key settings (CONFIG)

gas 0.0159 / liquid 0.0095 (typical for a P80-class unit) / gap 0.06 (spacing between the two lines) / clearance 0.3 (ceiling-void height) / group_distance 8.0 m (fits a 6 m structural grid) / chargeless 20 · max_length 50 (adjust per equipment model)

Duct auto-routingDuct / Ventilation Ventilation equipment → routed at a right angle to the nearest exterior wall → an exterior hood is placed automatically.
What to select
  • Ventilation equipment (selecting the equipment alone is enough in exterior-termination mode)
  • To connect two pieces of equipment, select the equipment + an exterior hood
What gets generated
  • Round or rectangular duct + an exterior-wall pipe hood (GDL part)
What happens internally
  1. Routes horizontally at the ceiling-void level (equipment top + 0.15 m)
  2. From each unit, exits at a right angle through the nearest exterior wall
  3. Places a pipe hood on the exterior face, facing outward
  4. When airflow is given, sizes the duct automatically with the equal-friction method (1.0 Pa/m, velocity ≤ 10 m/s, aspect ratio ≤ 4)
  5. Avoids beam/slab penetration issues and clashes with other systems or lighting
Key settings (CONFIG)

exterior_hood True (exterior-termination mode) / hood_round True (round hood) / flow (airflow in m³/h — sizes automatically when given) / diameter 0.15 (default Ø150) / clearance 0.15 (use a smaller value where the ceiling void is shallow)

Create override ruleReview helper Batch-creates a "graphic override" rule and combination that displays only the piping in red.
What it does
  • Creates an override rule named "MEP Piping — Red" inside the "Tapir" rule group
  • Creates and registers an override combination named "MEP Review"
One-time manual setup
  1. Document > Graphic Overrides > Graphic Override Rules
  2. Set the condition for "MEP Piping — Red" (e.g., layer is a piping layer)
  3. From then on, just select "MEP Review" in the 3D view to show only the piping in red
Clear highlightReset display
When to use it

Right after auto-routing, the new piping is highlighted in red for easy review (the model's actual color is unchanged). Once you're done checking, use this button to return to the normal display. For a persistent color scheme, use "Create override rule" instead.

05Color Coding

Telling systems apart by color

Color coding is done through Archicad's native MEP System feature. Each discipline is assigned its own MEP system, which carries a "3D material color" and a "2D pen color". Because the system is set at generation time, the piping is always color-coded in 2D, 3D, and on drawings — no need to switch a graphic override per view.

Drainage = blue

MEP system "Drainage". 3D material = blue, 2D = the closest blue pen.

Refrigerant = orange

MEP system "Refrigerant". 3D material = orange, 2D = the closest orange pen.

Duct = light green

MEP system "Ventilation". 3D material = light green, 2D = the closest light-green pen.

Set up MEP system colorsOne-time setup A palette button that creates the three MEP systems and sets their 3D material color and 2D pen.
What happens internally
  1. Creates the surface materials for each system color (blue / orange / light green) and reads their index
  2. Reads the pen set's RGB values via GetPens and auto-picks the closest pen to each color
  3. Creates "Drainage / Refrigerant / Ventilation" via CreateMEPSystems (material + outline/centerline pens)
Usage notes
  • Run once first — every auto-routed system afterward will be colored automatically
  • Existing piping keeps its previous color (color is fixed at generation time); regenerate on the relevant layer if you want existing piping recolored too
  • This feature relies on newer add-on commands (CreateMEPSystems / GetPens), so it requires one Archicad restart after installing them
06How it works

Principles shared by all three systems

Every button follows the same underlying flow. The rules a designer would apply on site are translated directly into the calculation.

01From selection to coordinates

Reads each selected element's type (fixture / morph / object) and 3D bounding box, then auto-classifies it by role. Hit-testing never trusts the API blindly — it's verified against real coordinates.

02Grid-parallel routing

Diagonal runs are disallowed; every route is built from right-angle segments along the X and Y axes only. Horizontal runs are aligned to a single ceiling-void level (equipment top + clearance) and kept concealed.

03Grouping and level management

Nearby fixtures / indoor units on the same story are grouped into a single main line (4 m for drainage, 8 m for refrigerant). Concealment rules are respected — piping never drops below the ceiling, and never penetrates the slab above.

04Structural check

Beam penetrations are approximately validated against "opening diameter ≤ 1/3 of beam depth, within the middle third of the span, at least 1.2× the opening diameter from any column face" — following steel and RC penetration rules to avoid disallowed openings or column clashes.

05Generated as real MEP elements

The computed route is generated as an actual Archicad MEP piping element via the custom CreateMEPRoutes command. The system name and pipe diameter are also finalized here.

06Automatic 2D labels

At the same time, a 2D text label (e.g. "Drainage Ø100") is placed at the midpoint of each horizontal run on the relevant floor plan (risers are excluded, and nearby labels are thinned out). Labels are placed on each system's own layer, so they follow the same show/hide and drawing rules as the piping.

07Review and redo freely

Generated elements land on their own discipline-specific layer (drainage = *992, refrigerant = *993, duct = *994, PS morph = *991) and are highlighted. This makes it easy to show/hide by discipline. You're always free to delete and re-run — the building itself is never affected.
