Claude Code は Anthropic 社の公式AIツールで、パソコン上でファイル作成やスクリプト実行ができる「AIの作業員」です。この引き継ぎ書に付属する /gdl スキル（AIへの作業指示書のセット）を所定のフォルダに置くと、上の流れが全自動になります。生成はすべて自分のPC内で完結し、モデル自体が外部に送られることはありません（Claudeとの会話・生成コードはAnthropicのサーバーで処理されます）。

ステップ 3Claude Code をインストールしてログインする

3-1. アカウントの準備（有料部分）

  • 定額プランの場合: claude.ai でアカウントを作成し、Pro プラン（またはMax）に加入します。無料プランのままでは Claude Code にログインできません。
  • 従量課金の場合: platform.claude.com（Claude Console）でアカウント作成 → クレジットを購入します。

3-2. インストール（無料）

Windows: スタートメニューで「PowerShell」を開き、次の1行を貼り付けて Enter:

irm https://claude.ai/install.ps1 | iex

Mac: ターミナルで:

curl -fsSL https://claude.ai/install.sh | bash

Node.js などの事前インストールは不要です（万一上のコマンドが失敗する場合の代替: Windowsは winget install Anthropic.ClaudeCode）。インストール後、いったんコマンドプロンプト/PowerShellを閉じて開き直してください。

3-3. 初回起動とログイン

  1. コマンドプロンプトで claude と入力して Enter。
  2. ブラウザが自動で開くので、3-1 で用意したアカウントでログインします（定額プランなら「Claude account」、従量課金なら「Console account」を選択）。
  3. ターミナルに Claude Code の画面が出れば成功です。/exit と入力すると終了できます。

公式ドキュメント: code.claude.com/docs（英語）

2回目以降・修正したいとき

  • 修正はそのまま会話で頼めます: /gdl さっきの本棚の棚板を5段にして背板も付けて（新しい名前で再生成されます）。
  • 生成物はすべて埋め込みライブラリの「Claude GDL」フォルダにまとまります。不要になったら配置した要素を削除するだけです。配置・変更は Archicad の［元に戻す］でも取り消せます。
  • 初回は環境チェックやひな型の自動調整が入るため数分かかることがあります。2回目からは速くなります。

/gdl と入力しても反応しないスキルの配置場所違いが大半。ステップ4のフォルダ構成（.claude\skills\gdl\SKILL.md）を確認し、必ず「GDL作業」フォルダの中で claude を起動する。
「Archicad に接続できません」Archicad が起動していない／プロジェクトを開いていない。開いてから再実行。複数起動時は Claude に「ポート19724で試して」と伝える。
「Tapir アドオンが見つかりません」ステップ2が未完了、またはバージョン違い。アドオンマネージャーで Tapir にチェックが入っているか確認。
「LP_XMLConverter が見つかりません」Archicad のインストールフォルダをエクスプローラーで「LP_XMLConverter」と検索し、見つかったパスを Claude にそのまま伝える。
初回にXML変換エラーが続くArchicadのバージョンによりオブジェクトのひな型調整が必要な場合があります。スキルが自動修復を試みます。その過程で「適当なオブジェクトを1つ .gsm 保存してほしい」と頼まれたら、Archicad で適当なオブジェクトを選択 →［ファイル］→［ライブラリとオブジェクト］→［選択内容に名前を付けて保存］で保存します（初回のみ）。
Tapir を入れてから Archicad の調子が悪い気がする（困ったときの戻し方）無効化すればいつでも元に戻せます。［オプション］→［アドオンマネージャー...］で Tapir のチェックを外して「OK」→ Archicad を再起動（またはアドオンファイル自体を一時的に別フォルダへ移動してから起動）。Archicad 本体やプロジェクトデータには影響しません。なお、バージョン違いのファイル（例: AC28 に AC29 用）を入れた場合はクラッシュではなく単に読み込まれないだけです。同様に、/gdl スキルをやめたいときは「GDL作業」フォルダを削除するだけで、Claude Code 自体も通常のアンインストールで削除できます。

技術メモ（引き継ぎを受けて改造する方へ）

/gdl スキルが行っていることは次の4段階です。すべてのファイルはテキストで、.claude\skills\gdl\ 内で確認・編集できます。

  1. GDL設計: Claude が依頼文からパラメータ（a=幅 / b=奥行 / zzyzx=高さ＋独自パラメータ）と3D/2Dスクリプトを作成し、template.xml のひな型に流し込む。
  2. 変換: Archicad 付属の LP_XMLConverter（xml2libpart）で XML → .gsm（バイナリのライブラリ部品）に変換。場所は Tapir の GetArchicadLocation コマンドで自動検出。
  3. 登録: Tapir の AddFilesToEmbeddedLibrary で埋め込みライブラリに追加し、ReloadLibraries で再読込。
  4. 配置: Tapir の CreateObjects で指定座標に配置。
  • 安全設計: スキルは「埋め込みライブラリへの追加」と「新規配置」しか行いません（既存要素の変更・削除はしない方針を SKILL.md に明記）。
