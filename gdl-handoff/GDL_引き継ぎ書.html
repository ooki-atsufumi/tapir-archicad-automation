GDL 引き継ぎ書

Archicad のオブジェクト記述言語 GDL（Geometric Description Language）を、これから引き継いで使う方向けの手順書です。Archicad 内蔵エディタでの GDL オブジェクト作成と、Tapir＋Python による GDLパラメータの一括操作の両方をカバーします。

対象: Archicad 25〜29 をお使いの方（プログラミング知識は不要） 所要時間: 約20分 作成日: 2026-08-16

全体像 — GDL でできること

GDL は Archicad に最初から内蔵されている、パラメトリックなオブジェクト（家具・建具・部品など）を作るためのプログラミング言語です。使い方は大きく2段階あります。

ステップ 1GDLマニュアルをダウンロードする

GDL の文法・全コマンドが載っている公式リファレンスです。下のボタンから Graphisoft 公式サイトの PDF がそのままダウンロードできます。

⬇ GDLリファレンスガイド（日本語版PDF・公式） 英語版PDF（公式）

  • PDF版はArchicad 23時点の内容ですが、GDLの基本文法はその後もほぼ変わっていないため入門・辞書用途には十分です。
  • 最新の英語版リファレンスはオンラインの GDL Center（Graphisoft公式） で常時公開されています。
  • Archicad のヘルプメニュー（［ヘルプ］→ ドキュメント類）からも GDLリファレンスガイドを開けます。オフライン環境の場合はこちらが確実です。

補足: マニュアルは Graphisoft の著作物のため、この引き継ぎ書には埋め込まず公式サイトへの直接ダウンロードリンクにしています（クリックすればそのままPDFが保存できます）。リンク切れの際は「GDLリファレンスガイド PDF」で検索するか、Archicadのヘルプメニューから開いてください。

ステップ 2Archicad だけで GDL を始める（追加インストール不要）

GDL エディタは Archicad に内蔵されています。まず「パラメータで大きさと材質を変えられる直方体」を作って流れをつかみましょう。

2-1. 新規オブジェクトを開く

  1. Archicad のメニュー ［ファイル］→［ライブラリとオブジェクト］→［新規オブジェクト...］ を選択します（GDLエディタが開きます）。
  2. 左上の「詳細」で サブタイプ＝オブジェクト のままでOKです。

2-2. 3Dスクリプトを書く

左側のリストから 3Dスクリプト を開き、次を貼り付けます。

! パラメータ化した直方体
! a=幅, b=奥行, zzyzx=高さ (Archicadの組み込みパラメータ)
MATERIAL "塗装-白"
BLOCK a, b, zzyzx

2-3. 2Dスクリプトを書く

同様に 2Dスクリプト を開き、次を貼り付けます（3D形状を平面図に投影する定番の1行です）。

PROJECT2 3, 270, 2

2-4. チェック → 保存 → 配置

  1. エディタ上部のチェックボタン（✓）でスクリプトの文法エラーがないことを確認します。
  2. ［ファイル］→［保存］で名前を付けて埋め込みライブラリに保存します（このプロジェクト内で使えるようになります）。
  3. ツールボックスのオブジェクトツールで配置し、設定ダイアログでパラメータ a / b / zzyzx を変えると形が変わることを確認します。

ここまでできたら、あとはマニュアル（ステップ1）を辞書代わりに、PRISM_（多角形柱）や REVOLVE（回転体）、FOR〜NEXT（繰り返し）などを追加していくのが定石です。既存の類似オブジェクトを開いてスクリプトを読むのも近道です（オブジェクト設定ダイアログから開けます）。

ステップ 3（任意）一括操作の準備 — Python と Tapir

配置済みオブジェクトの GDLパラメータを一覧化・一括変更したい場合のみ、次の2つを入れます。

3-1. Python のインストール

  1. https://www.python.org/downloads/ からインストーラーをダウンロード。
  2. インストーラー最初の画面で必ず「Add python.exe to PATH」にチェックを入れてから「Install Now」（ここが一番のつまずきポイントです）。
  3. コマンドプロンプトで python --version と入力し、バージョンが表示されれば成功（Mac はターミナルで python3 --version）。

3-2. Tapir アドオンのインストール

Tapir は Archicad に自動化用のJSONコマンドを追加する無料のオープンソースアドオンです（開発: ENZYME-APD）。お使いの Archicad のバージョンと OS に合ったファイルを1つダウンロードしてください。

Archicad バージョンWindowsMac
Archicad 29 TapirAddOn_AC29_Win.apx TapirAddOn_AC29_Mac.zip
Archicad 28 TapirAddOn_AC28_Win.apx TapirAddOn_AC28_Mac.zip
Archicad 27 TapirAddOn_AC27_Win.apx TapirAddOn_AC27_Mac.zip
Archicad 26 TapirAddOn_AC26_Win.apx TapirAddOn_AC26_Mac.zip
Archicad 25 TapirAddOn_AC25_Win.apx TapirAddOn_AC25_Mac.zip
  1. Mac は zip をダブルクリックで解凍しておきます（.bundle ができます）。Windows は .apx のままでOK。
  2. Archicad の ［オプション］→［アドオンマネージャー...］ →［有効なアドオンのリストを編集］で［追加...］→ ダウンロードしたファイルを選択 →「OK」。
  3. メニューバーに 「Tapir」メニューが表示されれば成功です。

一覧ページ: Tapir 最新リリース（GitHub）

ステップ 4（任意）GDLパラメータ操作スクリプト

下のボタンを押すと、スクリプト本体がそのままダウンロードされます（このHTMLファイル内に埋め込んであるため、ネット接続がなくてもダウンロードできます）。追加のPythonパッケージは不要です。

⬇ GDLパラメータ操作.py をダウンロード GitHub から入手（予備）

使い方

  1. Archicad でプロジェクトを開き、調べたいオブジェクト（ドア・窓・ランプも可）を選択します。
  2. GDLパラメータ操作.py をダブルクリックすると、選択要素の全GDLパラメータが GDLパラメータ一覧_日時.csv に出力されます（読み取りのみで安全です）。Excelでそのまま開けます（文字化け対策済み）。

コマンドプロンプトからは一括変更もできます。既定はドライラン（プレビューのみ）で、--apply を付けたときだけ実際に変更されます。

python GDLパラメータ操作.py                          … 選択要素のパラメータをCSVに一覧出力
python GDLパラメータ操作.py --type Object            … 選択の代わりに全オブジェクトを対象化
python GDLパラメータ操作.py --set gs_cont_pen=95     … 変更のプレビュー(まだ変更しない)
python GDLパラメータ操作.py --set gs_cont_pen=95 --apply  … 実際に一括変更する
  • パラメータ名は CSV 一覧の「パラメータ名」列で確認できます（例: gs_cont_pen は輪郭ペン）。
  • 文字列を設定する場合は --set パラメータ名="値" のように引用符で囲みます。
  • --apply での変更後も、Archicad の［編集］→［元に戻す］で取り消せます。
  • ロック中のパラメータは自動的にスキップされます。

トラブルシューティング

症状原因と対処
3D画面にオブジェクトが表示されない3Dスクリプトのエラーの可能性。GDLエディタのチェックボタン（✓）でエラー行を確認。BLOCK 0,0,0 のように寸法が0になっていないかも確認。
平面図に何も表示されない2Dスクリプトが空。まずは PROJECT2 3, 270, 2（3D形状の投影）を入れる。
マニュアルPDFがダウンロードできない社内ネットワークの制限の可能性。Archicad の［ヘルプ］メニューから GDLリファレンスガイドを開く方法が確実（インストール時に同梱されています）。
「Archicad に接続できませんでした」（スクリプト実行時）Archicad が起動していない／プロジェクトを開いていない。起動して開いてから再実行。複数起動時は --port 19724 を試す。
「Tapir アドオンが見つかりませんでした」ステップ3-2が未完了、またはバージョン違いのファイルを入れている。アドオンマネージャーで Tapir にチェックが入っているか確認。
「python は認識されていません」Python の PATH 設定漏れ。「Add python.exe to PATH」にチェックを入れて再インストール。
--set しても値が変わらない要素があるそのパラメータがロックされている（CSVの「ロック」列で確認）か、その要素にそのパラメータが存在しない。ドライラン表示のスキップ理由を確認。
一括変更を取り消したいArchicad の［編集］→［元に戻す］（Ctrl+Z / Cmd+Z）で戻せます。大量変更の前にプロジェクトを保存しておくとより安心です。
Tapir を入れてから Archicad の調子が悪い気がする（困ったときの戻し方）無効化すればいつでも元に戻せます。［オプション］→［アドオンマネージャー...］で Tapir のチェックを外して「OK」→ Archicad を再起動（またはアドオンファイル自体を一時的に別フォルダへ移動してから起動）。Archicad 本体やプロジェクトデータには影響しません。なお、バージョン違いのファイル（例: AC28 に AC29 用）を入れた場合はクラッシュではなく単に読み込まれないだけです。

技術メモ（引き継ぎを受けて改造する方へ）

付属スクリプトは Python 標準ライブラリのみで書かれており、Archicad の JSONインターフェース（http://127.0.0.1:19723）経由で次の Tapir コマンドを使っています。

  1. TapirCommand.GetSelectedElements（または公式 API.GetElementsByType）— 対象要素の取得
  2. TapirCommand.GetGDLParametersOfElements — 要素ごとの全GDLパラメータ（名前・型・値・ロック状態・配列サイズ）を取得
  3. TapirCommand.SetGDLParametersOfElements — パラメータの一括変更。配列パラメータは「リストを渡してまるごと差し替え」または「index1/index2（1始まり）で1要素だけ変更」の2通りが可能
