# SG エンジェル — GDL オブジェクト（仮設計画用）

ジー・オー・ピー株式会社（GOP）の**アルミ合金製 移動式室内足場「SG エンジェル」**を
Archicad の GDL パラメトリック オブジェクトにしたもの。
仮設計画図（配置検討・平面図・3D 確認・積算）で使うことを前提に作っている。

製品ページ: <https://gop.co.jp/products/ashiba/sg_angel.php>

---

## 仮設計画で効く作り込み

| ねらい | 実装 |
| --- | --- |
| **ありえない寸法を作らせない** | 天板高さはタイプごとの 100mm ピッチの段（M: 700/800/900、L: 1075〜1475）からのみ選択。手入力しても最寄りの段に丸められる |
| **連結架台を 1 オブジェクトで置く** | `nX` × `nY` で連結台数を指定。突き付け（離れ 0）も、離れを空けてブリッジを架ける配置も可能 |
| **手すりを面ごとに管理** | 外周 4 面を個別 ON/OFF。連結内側（離れ側）は `bGuardGap` で一括。連結すると内側手すりが自動で落ちる |
| **設置範囲が見える** | 補助脚を含む設置寸法（1560 × 1010）を破線で表示。躯体・搬入経路とのクリアランス検討用 |
| **図面で機種が読める** | 平面に「機種名 / H=天板高さ」を作図縮尺追従の文字で表示 |
| **並べやすい** | 各台の四隅・中心、全体外形の四隅・辺中央にホットスポット |
| **大量配置しても重くない** | 表示詳細度 3 段階（簡易 / 標準 / 詳細） |
| **そのまま拾える** | 機種名・仕様・台数・質量・作業床面積・許容荷重を読み取り専用パラメータで出力。一覧表（Element Schedule）にそのまま出せる |

## ファイル構成

```
SG_Angel/
  libpartdata.xml      パラメータ定義（HSF）
  scripts/
    1d.gdl             マスタースクリプト（諸元テーブル・派生値の計算）
    2d.gdl             2D スクリプト（平面シンボル）
    3d.gdl             3D スクリプト
    vl.gdl             パラメータスクリプト（選択肢・ロック）
  README.md
```

## 取り込み方

### 方法 A: HSF から開く（推奨）

Archicad の `LP_XMLConverter` で `.gsm` に変換する:

```bat
LP_XMLConverter.exe hsf2libpart "...\gdl-library\SG_Angel" "...\SG_Angel.gsm"
```

`LP_XMLConverter.exe` は Archicad インストールフォルダ直下にある。
生成した `.gsm` をライブラリフォルダに置いて読み込む。

> `libpartdata.xml` は Archicad で書き出したものではなく手書きのため、
> お使いのバージョンの `LP_XMLConverter` がスキーマ差分で弾く可能性がある。
> その場合は方法 B を使ってほしい（スクリプト本体はまったく同じものが入る）。

### 方法 B: 新規オブジェクトに貼り付ける

1. *ファイル > ライブラリとオブジェクト > 新規オブジェクト*
2. **パラメータ**タブで下表のとおりパラメータを作成
3. `scripts/` の各ファイルを対応するスクリプトタブに貼り付け
   （`1d.gdl` → マスター、`2d.gdl` → 2D、`3d.gdl` → 3D、`vl.gdl` → パラメータ）
4. 名前を付けて保存

## パラメータ一覧

`A` / `B` / `ZZYZX` および「数量・積算」グループはマスタースクリプトが自動計算し、
パラメータスクリプトでロックしている（編集不可）。

### ■ 機種

| 変数名 | 型 | 内容 | 既定値 |
| --- | --- | --- | --- |
| `iModel` | Integer | 機種（1 = 天板 1500×1000 / 2 = SG エンジェル750 天板 1500×750） | 1 |
| `iType` | Integer | タイプ（1 = M / 2 = L） | 1 |
| `hDeck` | Length | 天板高さ（タイプ別の 100mm ピッチにスナップ） | 0.9 |

### ■ 連結

| 変数名 | 型 | 内容 | 既定値 |
| --- | --- | --- | --- |
| `nX` | Integer | 連結台数（長手方向） | 1 |
| `nY` | Integer | 連結台数（短手方向） | 1 |
| `gapX` | Length | 長手方向の離れ（0 = 突き付け） | 0 |
| `gapY` | Length | 短手方向の離れ | 0 |
| `bBridgeX` | Boolean | 長手方向の離れにブリッジを架ける | 0 |
| `bBridgeY` | Boolean | 短手方向の離れにブリッジを架ける | 0 |

### ■ 手すり（感知フレーム）・補助脚

| 変数名 | 型 | 内容 | 既定値 |
| --- | --- | --- | --- |
| `bGuardFront` | Boolean | 手すり：手前（長手 1500 側） | 1 |
| `bGuardBack` | Boolean | 手すり：奥（長手 1500 側） | 1 |
| `bGuardLeft` | Boolean | 手すり：左妻（短手側） | 1 |
| `bGuardRight` | Boolean | 手すり：右妻（短手側） | 1 |
| `bGuardGap` | Boolean | 連結の離れ側にも手すりを立てる | 0 |
| `bOutrigger` | Boolean | 補助脚（転倒防止）を表示 | 1 |

### ■ 2D 表示

| 変数名 | 型 | 内容 | 既定値 |
| --- | --- | --- | --- |
| `b2DFootprint` | Boolean | 設置範囲（補助脚含む）を破線表示 | 1 |
| `b2DCaster` | Boolean | キャスター位置を表示 | 1 |
| `b2DDeckLine` | Boolean | 天板の目地を表示 | 0 |
| `b2DLabel` | Boolean | 機種名・天板高さを表示 | 1 |
| `txtSize` | RealNum | 文字サイズ [mm] | 2.5 |
| `bShowFill` | Boolean | 天板を塗りつぶす | 1 |
| `fillDeck` | FillPattern | 天板の塗りつぶし | 1 |
| `penFill` | PenColor | 塗りつぶしペン | 11 |
| `bFillBk` | Boolean | 塗りつぶしの背景を塗る（OFF = 背景透明） | 0 |
| `penFillBk` | PenColor | 背景ペン | 19 |
| `penContour` | PenColor | 天板 外形線ペン | 6 |
| `penDeck` | PenColor | 細線ペン（目地・キャスター・ブリッジ） | 11 |
| `penGuard` | PenColor | 手すりペン | 4 |
| `penFoot` | PenColor | 設置範囲ペン | 13 |
| `penText` | PenColor | 文字ペン | 6 |
| `lineBody` | LineType | 本体の線種 | 1 |
| `lineFoot` | LineType | 設置範囲の線種（破線） | 3 |

### ■ 3D 表示

| 変数名 | 型 | 内容 | 既定値 |
| --- | --- | --- | --- |
| `iLOD` | Integer | 表示詳細度（1 = 簡易 / 2 = 標準 / 3 = 詳細） | 2 |
| `matFrame` | Material | フレーム・脚の材質 | 18 |
| `matDeck` | Material | 天板の材質 | 18 |
| `matGuard` | Material | 手すりの材質 | 18 |
| `matCaster` | Material | キャスターの材質 | 27 |

### ■ 数量・積算（自動計算／編集不可）

| 変数名 | 型 | 内容 |
| --- | --- | --- |
| `sModelName` | String | 機種名（例: `SG エンジェル Mタイプ`） |
| `sSpec` | String | 仕様（例: `天板 1500x1000 / 天板高 900mm`） |
| `nUnitOut` | Integer | 台数 |
| `rMassTotal` | RealNum | 質量 合計 [kg] |
| `rDeckArea` | RealNum | 作業床 面積 [m²] |
| `rLoadSingle` | RealNum | 許容積載荷重（単体使用）[kg] |
| `rLoadPerSqm` | RealNum | 許容積載荷重（連結使用）[kgf/m²] |

### ■ 外形寸法（自動計算／編集不可）

`A` = 全体長さ、`B` = 全体幅、`ZZYZX` = 全体高さ（手すりを含む）。
いずれも機種・連結台数から決まるためロックしている。

## 座標系

- 原点 = 連結架台**全体の左手前角**（天板外形の角）、Z = 0 が床。
- ローカル **+X = 長手（1500）**、**+Y = 短手（1000 / 750）**。

## 諸元の出典と前提

### メーカー公表値（カタログ）にもとづくもの

| 項目 | 値 |
| --- | --- |
| 天板寸法 | 1500 × 1000 / 1500 × 750（SG エンジェル750） |
| 天板高さ M タイプ | 700 – 900（伸縮脚 100mm × 2 段） |
| 天板高さ L タイプ | 1075 – 1475（伸縮脚 100mm × 4 段） |
| 設置寸法（補助脚含む） | 長さ 1560 × 幅 1010 |
| 質量 | 28 – 33 kg |
| 許容積載荷重 | 単体使用 190 kg／連結使用 120 kgf/m² |
| 感知フレーム（短手側） | W1000 × H900（天板より）4.0 kg／W750 3.5 kg |
| 共通ブリッジ1500 | 8 kg（許容荷重 150 kg） |
| エンジェルキーパー | 2.6 kg |
| キャスター | W キャスター（2 輪） |

### このオブジェクトでの想定値（要確認）

外形寸法は上記の実寸どおりだが、以下は**カタログから確定できなかったため代表値**を入れている。
正確な値が必要な場合は 1d.gdl の該当行を書き換えてほしい。

- **SG エンジェル750 の質量**（M 25 kg / L 30 kg と仮置き）。1000 幅の値から按分した推定。
- **長手側 感知フレームの質量**（5.5 kg と仮置き）。
- **部材の断面寸法・脚位置・キャスター径・補助脚の形状**
  （脚芯位置 妻から 150 / 桁から 45、外管 50 × 30、キャスター φ100、取付面高さ 115 など）。
  メーカー website / 図面へのアクセスが取れなかったため、同社の可搬式作業台シリーズの
  一般的な構成から起こした。外形・設置寸法・天板高さは実寸なので**配置検討・干渉チェック
  には使えるが、部材レベルの詳細図として使うものではない**。
- **ブリッジ**は「離れを渡す作業床」として一般化して作図している。実製品の
  エンジェルブリッジ 1000 / 750・共通ブリッジ1500 の寸法体系とは対応していない。

### 計画上の注意（製品仕様）

- **SG エンジェル同士の連結には「足場の組立て等の業務に係る特別教育」修了者が必要。**
  連結（`nX` / `nY` > 1）を計画する場合は施工体制側の確認が要る。
- 連結時の許容積載荷重は 120 kgf/m²（単体使用時の 190 kg とは基準が異なる）。

## 制限事項

- **Archicad で実際に読み込んでの動作確認はしていない**（この作業環境に Archicad が無いため）。
  スクリプトは構文構造（if/endif、for/next、変換スタックの DEL 対応）を静的に検証済み。
- UI スクリプトは付けていない。標準のパラメータ一覧が
  Title でグループ分け＋ポップアップ選択になるため、そのままで実用に足ると判断した。
- 折り畳み状態（運搬・保管時）の表現は未実装。
